# PLACEHOLDERS.md

Every per-client value in this starter is one of three things:

1. **`{{TOKEN}}` placeholders** — visible markers left in copy/strings. Find them with:
   ```bash
   grep -rn "{{" app components lib public supabase --include='*.tsx' --include='*.ts' --include='*.json' --include='*.txt' --include='*.sql'
   ```
   (Ignore JSX double-brace expressions like `{{ opacity: 1 }}` or `{{ __html: html }}` — those are code, not placeholders.)
2. **`TODO(client):` comments** — inline instructions next to a value that needs setting. Find them with:
   ```bash
   grep -rn "TODO(client)" .
   ```
3. **Unset `@theme` token values** — neutral colour defaults in `app/globals.css` (see the bottom of this file).

### Environment variables (`.env.example` → `.env.local`)

All values in `.env.example` are placeholders and must be set per client:
`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `NEXT_PUBLIC_SITE_URL`,
`SUPABASE_SERVICE_ROLE_KEY`, `RESEND_API_KEY`, `ADMIN_NOTIFY_EMAIL`, and the optional `TWILIO_*` keys.

## 4. Unset `@theme` token VALUES — `app/globals.css`

Token **names** are permanent (the contract — see `token-map.md`). Only the **values** are placeholders.
Each is marked `/* TODO(client): set brand value */`:

| Token | Role | Placeholder value |
| --- | --- | --- |
| `--forest-deep` | band / primary (dark brand base) | `#1f2937` |
| `--forest` | band hover | `#374151` |
| `--green-mid` | link on light | `#2563eb` |
| `--gold` | accent / CTA | `#9ca3af` |
| `--gold-text` | accent for text on light (WCAG AA) | `#4b5563` |
| `--cream` | canvas | `#f7f7f5` |
| `--white` | panel / card | `#ffffff` |
| `--ink` | text | `#111827` |
| `--muted` | muted surface | `#ededeb` |
| `--muted-foreground` | secondary text | `#6b7280` |
| `--border` / `--input` | hairline borders | `#e5e7eb` |
| `--scrim-hero` | hero gradient (match band) | `rgb(31 41 55 / …)` |

> ⚠️ Read `token-map.md` first. `accent` is the CTA colour (NOT `primary`), and `primary === band`,
> so a CTA on a `band` background must use `accent`. There is no dark-mode block — `dark:` utilities are dead code.
