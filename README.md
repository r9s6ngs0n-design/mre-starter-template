# Starter Template

A reusable Next.js 16 + Supabase + Tailwind v4 starter with a clean, brandless skeleton.

```bash
pnpm install
cp .env.example .env.local   # fill in real values
pnpm dev                     # http://localhost:3000
```

Verify: `pnpm typecheck` · `pnpm lint` · `pnpm build`

**Start here:** [`STARTER_README.md`](./STARTER_README.md) for the full per-client
customization guide, and [`PLACEHOLDERS.md`](./PLACEHOLDERS.md) for every value to set.

Design/merge reference: [`INTEGRATION_CONTRACT.md`](./INTEGRATION_CONTRACT.md),
[`ARCHITECTURE_ANALYSIS.md`](./ARCHITECTURE_ANALYSIS.md), [`token-map.md`](./token-map.md),
[`component-map.md`](./component-map.md).
