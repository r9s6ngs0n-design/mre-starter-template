# MR ESTATES — Integration Contract

> Companion to `ARCHITECTURE_ANALYSIS.md`. This is the **exact interface surface** that a v0
> design pass and the merge step must target. Every name, path, and type below is copied from the
> actual source (read-only). Where the code and the types disagree, it is flagged ⚠️.
>
> **Path note:** the query asked about `src/lib/`. This repo has **no `src/`** — application code
> lives at the **repo root**: `lib/`, `app/`, `components/`, `contexts/`, `hooks/`. The TS alias
> `@/*` maps to the repo root (`tsconfig.json`). Use `@/lib/...`, not `@/src/lib/...`.
>
> **`supabase.ts` note:** there is no single `lib/supabase.ts`. The Supabase layer is the folder
> `lib/supabase/` with four entry points: `client.ts`, `server.ts`, `middleware.ts`, `admin.ts`.

## 0. Canonical Types (import these; do not re-declare)

All DB types come from `@/lib/database.types` (generated by `supabase gen types`).

```ts
// Exported by @/lib/database.types — THESE EXIST:
export type Json = string | number | boolean | null | { [k: string]: Json | undefined } | Json[]
export type Database = { /* full schema */ }
export type Tables<Name>        // Row type for a table/view, e.g. Tables<'listings'>
export type TablesInsert<Name>  // Insert type, e.g. TablesInsert<'leads'>
export type TablesUpdate<Name>  // Update type
export type Enums<Name>         // enum union, e.g. Enums<'listing_category'>
export type CompositeTypes<Name>
export const Constants          // runtime enum arrays (see below)
```

### Enum values (source of truth = `Constants.public.Enums`)

```ts
listing_category : "project" | "buy" | "commercial" | "rent"
listing_status   : "available" | "under_offer" | "sold" | "leased" | "coming_soon"
lead_category    : "buyer" | "vendor" | "landlord" | "tenant"
user_role        : "admin" | "agent" | "user"
booking_status   : "pending" | "confirmed" | "cancelled" | "completed"
inspection_status: "registered" | "attended" | "cancelled"
```

### ⚠️ Missing type aliases (compile only because `ignoreBuildErrors: true`)

`lib/queries.ts`, `lib/queries-server.ts`, `lib/slugUtils.ts`, `lib/leads.ts`, and
`contexts/auth-context.tsx` all `import type { ListingCategory | UserRole | LeadCategory } from
'@/lib/database.types'` — **but `database.types.ts` does not export those names.** They currently
resolve to `any`. When typing against this contract, use the real equivalents:

```ts
type ListingCategory = Enums<'listing_category'>  // "project" | "buy" | "commercial" | "rent"
type UserRole        = Enums<'user_role'>          // "admin" | "agent" | "user"
type LeadCategory    = Enums<'lead_category'>       // "buyer" | "vendor" | "landlord" | "tenant"
```

## 6. Contract caveats for the merge step

1. **Two read modules, identical names-ish, different failure modes.** Server Components import
   `get*` from `@/lib/queries-server` (returns empty/null). Client components import `fetch*` from
   `@/lib/queries` (throws). Do not cross the streams.
2. **Category casing differs by layer.** DB/`Enums` use lowercase (`"buy"`); the legacy
   `Property.category` uses uppercase `Category` (`"BUY"`). `listingToProperty` is the only
   sanctioned bridge.
3. **`[id]` on the property route is the listing `slug`**, not the uuid `id`. `getListingBySlug`
   takes the slug; `getDocumentsForProperty` / JSON-LD take `listing.id`.
4. **Missing enum aliases** (`ListingCategory`/`UserRole`/`LeadCategory`) are currently `any`. If
   you re-enable type-checking, add them to `database.types.ts` or switch imports to
   `Enums<'…'>`, or these helper signatures will fail to compile.
5. **Server-only modules** must never be imported into `'use client'` files: `lib/supabase/server.ts`,
   `lib/supabase/admin.ts`, `lib/queries-server.ts`, `lib/supabase/middleware.ts`.
6. **Env contract:** `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   (or `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`), `SUPABASE_SERVICE_ROLE_KEY` (server),
   `NEXT_PUBLIC_SITE_URL`. Browser `createClient()` throws when the first two are absent; server
   `createClient()` returns `null` (callers already handle null).
